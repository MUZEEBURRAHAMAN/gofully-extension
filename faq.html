Frequently Asked Questions

Everything You Need to Know

Got questions about capture modes, OCR text extraction, CleanShot-style annotation, PDF exports, or privacy? We've got answers.

GoFully is an all-in-one browser screenshot, OCR text extraction, and visual annotation tool. It allows you to capture full scrollable webpages, viewports, custom regions, or scrolling areas, annotate them with arrows, callouts, and step numbers, redact sensitive data, extract text with local OCR, and export to PNG, 4K HD, or multi-page PDF.
GoFully utilizes Chrome DevTools Protocol (CDP) `Page.captureScreenshot` for single-shot, pixel-perfect full-page renders. On pages where CDP is unavailable, it automatically falls back to an intelligent scrolling stitcher that temporarily hides sticky headers, triggers lazy-loaded images, and stitches viewports seamlessly into an OffscreenCanvas.
Yes! GoFully provides two dedicated partial modes:
• Selected Area (Region): Click and drag a custom rectangle with live pixel dimension indicators and crosshair guides.
• Scrolling Area: Select a fixed window/box (such as a chat thread or scrollable code box) and scroll through it to stitch only that element.
Yes. GoFully includes a full-featured CleanShot X-inspired Annotation Studio. You can add straight and curved arrows, rectangles, ellipses, lines, freehand drawing with a pen, handwriting text with Caveat styling, auto-incrementing step bubbles (`1`, `2`, `3`…), and spotlight focus highlights.
GoFully includes 3 dedicated privacy tools inside the editor:
• Glass Smooth Blur: Gaussian-style smooth visual softening.
• Mosaic Pixelate: Classic mosaic pixel blocks.
• Redact Blackout: Complete opaque solid security blocks.
When you trigger Capture Text (OCR), drag a selection over any image, chart, or video frame. GoFully runs an on-device WebAssembly optical character recognition worker (Tesseract.js) to recognize all characters locally. The extracted text is instantly copied to your clipboard.
Yes. GoFully can export to PNG (Native, 1080p HD, and 4K UHD), JPG, and auto-paginated A4 Multi-Page PDF documents using our built-in PDF generator without losing image resolution.

Google Chrome places strict security restrictions that prevent all extensions from executing content scripts on browser internal pages (such as `chrome://*`, `edge://*`, and the Chrome Web Store). GoFully provides a polished "Unsupported Page" indicator informing you when a system page is active.
GoFully works on virtually all standard HTTP and HTTPS websites. Some sites with complex cross-origin iframes or custom infinite scroll scripts may require using Visible Area or Selected Area mode if full-page scrolling encounters dynamic DOM locks.
• Full Page: `Alt+Shift+F` (Windows/Linux) or `⌥⇧F` (Mac)
• Visible Area: `Alt+Shift+V` (Windows/Linux) or `⌥⇧V` (Mac)
You can customize these hotkeys anytime in Chrome's shortcut manager at `chrome://extensions/shortcuts`.
