## Key Positioning Messages

### vs GoFullPage (10M+ users, main competitor)
- "GoFullPage does full page capture. GoFully does that plus scrolling-area capture, OCR, and a free editor."
- "GoFullPage charges $1/month for editing and PDF. GoFully includes both free."
- "GoFullPage can't capture scrollable elements, selected regions, or extract text with OCR."

### vs FireShot (1M+ users)
- "FireShot has no scrolling area or scrollable element capture, and no OCR."
- "FireShot's editor is basic — no blur, no step numbers, no arrows."
- "FireShot uploads to cloud services. GoFully stays 100% local."

### vs Awesome Screenshot (3M+ users)
- "Awesome Screenshot requires an account and sends data to their servers."
- "Awesome Screenshot's advanced features are behind a paywall."
- "GoFully matches their feature set, adds local OCR, with zero cloud dependency."

### vs Nimbus Screenshot (2M+ users)
- "Nimbus requires account creation to use basic features."
- "Nimbus still uses Manifest V2 — Google is deprecating it."
- "GoFully offers scrollable element capture and on-device OCR, which Nimbus doesn't."

## Unique Selling Propositions (USPs)

1. **Only extension with 5 capture modes** — full page, visible, selected, scrolling area, and OCR text capture
2. **Only free scrollable element capture** — chat boxes, code panels, data tables
3. **Built-in on-device OCR** — no competitor above offers this at all
4. **CleanShot-style scrolling area in Chrome** — previously macOS-only
5. **Free editor with blur + redaction + step numbers** — competitors paywall these
6. **PNG, JPG, and WebP export with adjustable quality**, plus auto-paginated PDF
7. **100% offline architecture** — zero network requests, ever
8. **Manifest V3 native** — future-proof, not retrofitted

## GEO / AEO Note

Every USP above is written as one self-contained, factual sentence on
purpose — this is the format generative answer engines (ChatGPT,
Perplexity, Google AI Overviews) and traditional answer boxes both prefer to

shape rather than folding multiple claims into one marketing sentence.
