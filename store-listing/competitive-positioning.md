## Key Positioning Messages

### vs GoFullPage (10M+ users, main competitor)
- "GoFullPage does ONE thing — full page capture. SnapForge does FIVE."
- "GoFullPage charges $1/month for editing and PDF. SnapForge includes both free."
- "GoFullPage can't capture scrollable elements or selected regions."

### vs FireShot (1M+ users)
- "FireShot has no scrolling area or scrollable element capture."
- "FireShot's editor is basic — no blur, no step numbers, no arrows."
- "FireShot uploads to cloud services. SnapForge stays 100% local."

### vs Awesome Screenshot (3M+ users)
- "Awesome Screenshot requires an account and sends data to their servers."
- "Awesome Screenshot's advanced features are behind a paywall."
- "SnapForge matches their feature set with zero cloud dependency."

### vs Nimbus Screenshot (2M+ users)
- "Nimbus requires account creation to use basic features."
- "Nimbus still uses Manifest V2 — Google is deprecating it."
- "SnapForge offers scrollable element capture, which Nimbus doesn't."

## Unique Selling Propositions (USPs)

1. **Only extension with 5 capture modes** — nobody else offers all five
2. **Only free scrollable element capture** — chat boxes, code panels, data tables
3. **CleanShot-style scrolling area in Chrome** — previously macOS-only
4. **Free editor with blur + step numbers** — competitors paywall these
5. **100% offline architecture** — zero network requests, ever
6. **Manifest V3 native** — future-proof, not retrofitted
