# Support for GoFully

Thank you for using GoFully! We want you to have the best experience capturing, editing, and annotating screenshots.

---

## 1. Documentation & Guides

Before asking a question or filing a bug, check out our comprehensive guides and FAQs:

- **Documentation & Tutorials**: [https://gofully-extension.vercel.app/guides](https://gofully-extension.vercel.app/guides)
- **Frequently Asked Questions**: [https://gofully-extension.vercel.app/faq](https://gofully-extension.vercel.app/faq)
- **Release Roadmap**: [https://gofully-extension.vercel.app/roadmap](https://gofully-extension.vercel.app/roadmap)

---

## 2. Community & Bug Reports

If you encounter an issue or want to request a new feature:

- **Bug Reports**: Open an issue using the [Bug Report Template](https://github.com/MUZEEBURRAHAMAN/gofully-extension/issues/new?template=bug_report.md).
- **Feature Requests**: Submit ideas via the [Feature Request Template](https://github.com/MUZEEBURRAHAMAN/gofully-extension/issues/new?template=feature_request.md).
- **Discussions**: Start a discussion in [GitHub Issues](https://github.com/MUZEEBURRAHAMAN/gofully-extension/issues).

---

## 3. Chrome Web Store Reviews & Feedback

If you love GoFully, leaving a review on the [Chrome Web Store](https://chromewebstore.google.com/detail/gofully-full-page-screens/fclnndfkcnacglfklloicapchdfppkph) helps more users discover the extension.

For direct inquiries or partnership questions, reach out via the GitHub repository maintainer contact.
