## 10. FAQ (objection handling)

**Is GoFully really free?**
Yes. Every capture mode, the editor, OCR, auto-redact, Beautify, guides and PDF export are free. There's no paid plan.

**Do you see or store my screenshots?**
No. GoFully runs entirely in your browser. It has no account system and no server that receives images.

**Will it capture long pages and pages with sticky headers?**
Yes. GoFully scrolls the page for you, waits for images that load as you scroll and keeps sticky headers and fixed bars from repeating in the result.

**Which browsers does it work in?**
Chrome and browsers built on it, such as Edge, Brave, Arc and Opera. Install it from the Chrome Web Store.

**Can I edit a screenshot after I take it?**
Yes. Add arrows, shapes, text, numbered steps, highlights and blur, crop it, or style it with Beautify. Then copy it or save PNG, JPG, WebP or PDF.

**What languages can it read?**
English, Spanish, French, German, Portuguese and Simplified Chinese. The language files are bundled, so text capture works offline.

**Can I hide private details before I capture?**
Yes. Redact page covers emails, card numbers, phone numbers, ID numbers and API keys on the live page, plus anything you click, then you capture as usual. Done puts the page back.

**Can GoFully measure spacing or pick colors?**
Yes. Measure shows any element's size, padding, margin and text style, the gap between two elements, and a free ruler. It also picks any color on screen and copies the hex value.
